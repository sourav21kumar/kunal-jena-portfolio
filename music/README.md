# Music

Drop your audio files here with these exact names (MP3 recommended, ~128–192 kbps to keep the site light):

| File                | Song                              |
|---------------------|-----------------------------------|
| `fairytale.mp3`     | Fairytale — Alexander Rybak       |
| `snowman.mp3`       | Snowman — Sia                     |
| `starboy.mp3`       | Starboy — The Weeknd ft. Daft Punk|
| `hurts-so-good.mp3` | Hurts So Good — Astrid S          |

To change titles, artists or file names, edit `CONFIG.tracks` at the top of `script.js`.

The player lives in the About section ("Designing to"). If a file is missing, the player shows a friendly note with a "Listen on Spotify" link instead of breaking.

Note: commercial songs are copyrighted — only upload files you have the rights to publish.
For a public site, a safer option is to keep the Spotify links (no files needed).
